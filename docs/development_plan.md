# 完善方案：带定位误差与绕轴柔顺的组合对接

下一阶段的主任务是：**从侧方初始位姿出发，移动到估计目标上方，低速下降，
利用接触过程中的平动与绕轴柔顺完成插入和保持。**

## 对原有接口的认识

`male_cone.xml` 的公头内部安装角为绕局部 z 轴 40°；母头有独立安装位姿。
还要叠加末端向下的姿态，才能确定两者真实相对姿态。因此，零新增定位误差
不等于接口完美配合，40° 也不能直接解释为末端需要补偿的角度。

接触力矩引起的绕插入轴转动是任务允许、需要观察的行为。评价时分别处理：

- **绕轴转动**：记录实际角度、接触后转角和轴向力矩，不将偏离期望 yaw 自动判为失败。
- **倾斜**：约束公头轴线相对母头轴线的夹角。
- **进给和横偏**：使用真实母头坐标系测量，而非仅看相对规划轨迹的误差。

不能预设“降低绕轴刚度一定更好”；阻尼、转动惯量、摩擦与接触几何会共同影响结果。

## 已落地的一个组合场景

入口：`scenes/iiwa14_compliant_insertion.yaml`，机器人为 iiwa14，默认控制器为
`se3_lie`，保留固定基座和零重力研究条件。

| 阶段 | 参考位姿与要求 |
|---|---|
| 起点 | EE 位于 `[-0.12, 0.40, 0.55] m`，从侧方出发 |
| 必要时抬升 | 初始高度低于上方路点时，先在原 XY 抬升 |
| 接近 | 到估计母头上方；完成姿态过渡 |
| 下降 | 沿独立插入轴到入口参考平面 |
| 插入 | 低速继续进给，接触后允许轴向转动 |
| 保持 | 轨迹结束后继续保持 8 s，验收末 1 s 的稳定状态 |

每段位置走直线，姿态走 SO(3) 插值，二者共享五次时间函数，路点处速度与加速度
归零。此场景使用平滑路点轨迹，不声称时间最优。已有 SE(3)-TOPP 和旧对接场景仍有
独立的回归用途。

起点与终点已独立：终点由**估计目标**及入口/进给参数确定，不再由初始位置加
`stroke` 推导；插入方向固定为世界 -Z。本版支持竖直母头的水平偏差和 yaw 偏差，
倾斜目标会明确报错。

### 真实目标与估计目标

- `target.pos / target.quat`：MuJoCo 中的真实母头，仅供物理和评估。
- `docking.estimate_pos / estimate_yaw_deg`：规划器得到的估计。
- 默认误差：世界 XY `[+2, -2] mm`，额外 yaw `+5°`，一次试验内固定。
- 批量实验构造器根据真值产生受控误差；规划器只接收构造后的估计。

本接口在 iiwa14 的受控 EE frame 为 `cylinder_link`，它与公头根 frame 对齐。
`entry_height: 0.070` 是该 frame 相对母头根的入口参考高度；`clearance: 0.060`
使上方路点相对母头根高 0.130 m。`command_depth: 0.040` 是从入口平面向下的
参考行程，末端可能被接触阻挡，不要求达到过盈参考点。

这些尺寸不能原样移植到任意工具或 FR3；移植时应先核对受控 frame、工具安装偏移
和几何接触高度。

### 绕轴阻抗

六维参数顺序是 `[x, y, z, rx, ry, rz]`，在控制器 body 坐标约定下使用。
本场景末端 z 轴指向插入方向，所以末项控制绕插入轴的柔顺：

- 平动刚度 `[80, 80, 200] N/m`；倾斜刚度 `[25, 25] N·m/rad`。
- 对比绕轴刚度 `25` 和 `0.5 N·m/rad`，两组其余参数完全相同。
- 转动惯量均为 `1 kg·m²`，转动阻尼均为 `10 N·m·s/rad`。
- 轴向载荷来自阻抗对过盈参考的响应；当前没有额外叠加力控或绕轴搜索动作。

初次试验使用较小转动惯量/阻尼时，组合偏差下出现横向残差和接触振动。当前参数
使用更保守的惯量、阻尼和保持时间；门禁阈值未放宽。试验曲线应和参数一同解释。

## 将小实验合并为一个矩阵

统一入口：`experiments/insertion_suite.py`。所有工况都包含完整接近、下降、插入和
保持过程；无需分别维护“换初值演示”“上方路点演示”“偏差演示”和“转动柔顺演示”。

| 工况 | XY 偏差 | 额外 yaw 偏差 | 比较 |
|---|---|---|---|
| nominal | 0 | 0 | 高/低绕轴刚度 |
| xy | `[+2, -2] mm` | 0 | 高/低绕轴刚度 |
| combined | `[+2, -2] mm` | `+5°` | 高/低绕轴刚度 |

总计六次完整仿真；保持同一几何、初值、运动参考、惯量、阻尼和其他刚度，单独考察
绕轴刚度。这里的 nominal 仅代表零新增估计误差。

自由空间数学验证和接触回归仍分开保留：前者能隔离模型/运动学问题，后者能锁定
接触行为。旧 2×2 框架研究也保留，避免把控制器比较与绕轴刚度消融混为一谈。

```bash
# 单个默认组合场景；时长自动覆盖完整轨迹及保持
uv run docking --scene scenes/iiwa14_compliant_insertion.yaml

# 六组实验、统一数据/表格/曲线与场景预览
MUJOCO_GL=egl uv run python experiments/insertion_suite.py --preview

# 只看组合偏差下的柔顺组
MUJOCO_GL=egl uv run python experiments/insertion_suite.py \
  --case combined --profile compliant --preview

# 六组完整诊断 + nominal 两种刚度的半步长/SDF 迭代加密对照，共十组
MUJOCO_GL=egl uv run python experiments/insertion_suite.py \
  --diagnose --sensitivity --preview --out runs/contact_diagnostics_20261002

# 只重算诊断门禁和重绘；保留原始数据及原运行指纹
MUJOCO_GL=egl uv run python experiments/insertion_suite.py \
  --reanalyze --sensitivity --out runs/contact_diagnostics_20261002

# 一段视频覆盖所有运动阶段与路点坐标系
MUJOCO_GL=egl uv run docking --scene scenes/iiwa14_compliant_insertion.yaml --record
```

输出到 `runs/compliant_insertion/`：`report.md`、`comparison.png/pdf`、可选
`scene_preview.png/pdf`；各组含 NPZ 原始时序、JSON 完整配置/路点/门禁和 log。
`manifest.json` 记录关键依赖版本与源码指纹。每次运行建议指定不同 `--out` 以保存
试验历史；默认目录会更新同名输出。

`--quick` 只执行 2 s 并标为 INCOMPLETE。完整运行任何一组门禁失败，批量入口退出码为 2；
失败行和原始数据照常保存，不能把脚本成功产图当成全部工况成功。

`--diagnose` 在同一控制循环中被动记录求解时刻的 F/T、逐接触位置/载荷与工具惯性项。
控制参数与反馈保持原样。`mj_step` 后关节状态已积分到 `t+dt`，接触、传感器和
Cartesian 变换仍对应求解时刻 `t`；新通道保存两种时间及积分前的关节状态，避免混用。
诊断 NPZ 键以 `diagnostic_` 开头；同名 `contacts.npz` 保存逐接触记录。

几何参考独立于 SDF：从编译网格恢复到接口根坐标系，扫描竖直射线的上下包络，
求各 yaw 的首个无重叠高度，再细化紧凑相位。现有冠形网格得到约 `4.25° / 47.19 mm`
等四个近似参考；它们不是严格相同，90° 重复的采样高度差最大约 0.38 mm。
研究容差为横偏 0.5 mm、倾斜 0.5°、相位 2°、轴向/重叠 0.75 mm，检查末 1 s 的五个位姿。
这些容差不代表制造公差；射线采样也不替代连续网格相交检测。`SEATED_CANDIDATE`
表示满足此研究几何参考，锁紧仍未验证。

新增验收分别报告：原 F/T/进给门禁、采样几何状态、**真实接口接触合力/轴矩门禁**、
综合评估。接触门禁沿用同一 40 N / 2 N·m 限值，取对公头的合载荷、关于公头根的力矩；
不把 F/T 惯性抵消当成接触安全。综合 `CANDIDATE_PASS` 还要求原稳定保持门禁通过，
且载荷分解残差 ≤1e-6 N / N·m。`--diagnose` 下综合失败会返回退出码 2。

输出增加 `geometry_reference.json/png/pdf`、`load_diagnostics.png/pdf`、
`contact_peaks.png/pdf` 和可选 `sensitivity.png/pdf`。局部图展示 **F/T 轴矩峰值时刻**
的原始接触点与力矢量，采用统一缩放和半透明公头。接触点和力箭头投影到图面，
忽略遮挡，便于观察接口内部的载荷。几何 JSON 保存资产指纹、网格拓扑、加密变化、
SDF 迭代与距离场深度对照；重新分析另存 `analysis_manifest.json`。
重分析会核对记录配置和接口资产，配置或资产改变时要求使用原场景或重新标定。

本轮十组诊断的原六组基线仍为 3 PASS / 3 FAIL；只有 xy/combined 低刚度组符合采样
几何候选，但六组真实接触轴矩峰值均超过 2 N·m，因此**当前没有综合通过工况**。
nominal 的半步长或迭代加密可使原门禁通过，但几何仍未就位，不能据此宣称任务完成。

## 验收定义与研究边界

PASS 是**当前声明的进给/接触稳定门禁**：

- 运动及保持阶段执行完整；最后 1 s 的入口平面进给量至少 17 mm。
- 最后 1 s 横偏 ≤4 mm、倾斜 ≤5°，线速度 ≤3 mm/s、角速度 ≤2°/s。
- 最后 1 s 至少 95% 样本维持公母头接触。
- 全程力范数峰值 ≤40 N、轴向力矩峰值 ≤2 N·m、关节力矩限幅比例 ≤1%。
- 无插入阶段之前的接口碰撞、无接口之外的碰撞、无关节位置越限或非有限数据。

日志中的 `depth_mm` 从**指定入口参考平面**起算，包含接触前的空行程；
`post_contact_advance_mm` 单独报告首次接触后的继续进给。两者都不等于经过 CAD
标定的啮合深度。现有模型尚没有完全就位/锁紧状态的几何定义，因此不能声称已经
验收完整机械配合。低刚度组也可能失败；应按表格及失败原因评价，不能只挑峰值力。

启动前检查初始 IK 与沿参考路径采样的连续 IK 分支；实际碰撞由完整物理运行判定。
这不是带障碍物的全局避障规划器。改变初值后应重新完整验收。

   惯性扰动时，先核验静载/惯性补偿及误触发；模型内部真值仍只用于评分。
4. **mjviser**：作为可选被动显示/记录回放后端，复用已有路点坐标系、真值/估计
   目标和 NPZ，不另建一套实验；先验证显示与坐标变换，再增加浏览器交互。
5. **制造与扩展验证**：输出新轮廓的 STEP，核对孔位、公差和加工/强度；FR3、目标
   倾斜、实机、锁紧和自由漂浮基座分别建立验收范围。
