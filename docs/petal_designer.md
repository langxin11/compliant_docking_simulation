# PetalDock 交互调形

在项目根目录启动：

```bash
uv run python experiments/petal_designer.py
```

打开 http://127.0.0.1:8766。若端口占用，使用 `--port 8767` 指定新端口。
不需要安装新的依赖，不访问外部资源；服务只监听本机。
默认窄平顶参数为平顶半角 **1°**、斜坡过渡比例 **0.3**（平顶总宽2°）。

通过SSH在自己的电脑执行 `ssh -L 8766:127.0.0.1:8766 xiao@100.83.211.73`，
保持连接，再在自己电脑打开 http://localhost:8766。
本地端口也可改变，例如 `-L 18766:127.0.0.1:8766` 对应 http://localhost:18766。
访问检查接受转发后的本地端口，仍要求浏览器使用本机地址及同源请求。

## 操作

- 用滑块或数值框调整平顶半角、角向过渡、导向高度、边缘圆滑和轴向余量。
- 用单侧视图比较外形，用两侧配合观察45°翻转配合，用剖切检查内部间隙。
- 拖动模型旋转、滚轮缩放，或切换斜视、侧视、俯视；可显示两端坐标轴。
- 展开“两侧偏差与接近距离”调整预览的 XY、绕轴、倾斜偏差及接近距离。
  它们只改变观察姿态，不运行运动规划、柔顺控制或接触仿真。
- “保存候选”将参数另存到 `runs/designs/petal_guidance/candidate_*.json`，同时提供下载链接。
  “加载参数”可恢复保存的几何参数；预览姿态不作为控制或工况配置导入。

## 与当前模型的关系

三维花瓣直接调用 `prepare_petal_guidance.py` 的参数化曲面和网格函数，预览使用 `angular_samples=97`、`radial_samples=7`（圆角采样参数）；
原正式候选使用257与13。径向节点由圆角与过渡配置生成，并非固定97×7顶点网格。
两者共用几何定义，预览是较粗的离散近似，不承诺网格逐点相同。底座、安装孔和安装板直接读取原 OBJ。
四花瓣在浏览器中以90°间隔复用同一网格。浏览器坐标使用毫米，原仿真资产仍用米。

外径100 mm、导向环内径64 mm和安装结构固定。完整制造设计需要把这些尺寸与孔位
一起参数化；此工具用于选择导面轮廓，不生成制造CAD或完整动力学模型。

名义法兰间距按 `2×(8+6)+导向高度+轴向余量` 毫米计算。改变导向高度或轴向余量时，
原止挡仅以安装板顶面为基准沿轴缩放以预览落座位置，圆角也会随之改变。
正式模型需要重建止挡实体/圆角、碰撞、惯量、配合 site、落座元数据和场景进给量。
边缘圆滑在三维网格中生效；角向轮廓图显示未加边缘圆滑的解析工作面。

未圆滑的解析面仍满足 `h(r,θ)+h(r,45°−θ)=导向高度`。该恒等式只说明名义互补性，
不是碰撞收敛、制造可行、连续捕获范围或载荷通过的证据。

原径向对照曾在三组含15°偏航工况中载荷超限，仅保留为历史负面对照。所有保存文件
标记 `UNVALIDATED_DESIGN`，同时记录完整参数、源码/原模型信息哈希和后续重建要求。
不会改动原接口、冻结实验、场景或控制器。

## 选定以后

提供保存的候选文件名，即可据其几何参数生成新的独立模型版本，补齐制造/动力学
资产和配合基准，再用相同偏差工况、摩擦、速度和载荷门槛与窄平顶基线比较。
本工具保存的参数文件不是现有生成器的命令行配置；不能直接交给旧生成器宣称完成模型。

## 2026-10-03 选定参数

本次候选为平顶半角 **1°**、斜坡过渡比例 **0.3**，其余几何参数沿用窄平顶方案。
平顶总宽为2°。每段43°的升/降斜坡，两端各30%用于圆滑，中间40%为直线段；
增加圆滑比例会缩短直线段，因此直线段的坡度也会改变。

以保存的候选作为页面初始轮廓：

```bash
uv run python experiments/petal_designer.py --design assets/interfaces/petal_guidance/angle1_blend030/selected_design.json
```

起始轮廓下拉框提供当前默认窄平顶，以及通过 `--design` 载入的用户候选。
径向实验仅作为历史负面对照，不在交互界面展示；底层算法与历史资产保持原状。
若已有服务在运行，需要先结束该服务再以此命令启动。
当前服务已载入此候选，SSH转发与访问端口用法不变。

独立仿真资产由新增的保存参数构建器生成：

```bash
uv run python experiments/prepare_petal_design.py \
  --design assets/interfaces/petal_guidance/angle1_blend030/selected_design.json \
  --out runs/generated_assets/petal_guidance/angle1_blend030
```

生成文件先放在 `runs/generated_assets/`；审查并冻结后才纳入 `assets/`。
输出目录已存在时会拒绝覆盖。此构建器只允许调整导面形状，导向高度和轴向余量
必须沿用18 mm与0.4 mm，否则要求先重建安装/止挡CAD。构建器记录自身与原生成器
哈希，并更新整体惯量；不会修改旧生成器的候选策略。

独立场景为 `scenes/iiwa14_petal_angle1_blend030.yaml`。
代表工况验证采用原控制器、原载荷门槛，以及已冻结窄平顶数据作为历史参考；
历史参考并非本次重新运行的基线。查看 `runs/petal_angle1_blend030_20261003` 中的
实际结果，再判断是否采用此候选。

## 2026-10-05 交互与输入加固

默认窄平顶改为半角1°、过渡0.3，并移除起始轮廓选择器中的径向实验对照。
普通界面移除径向导面宽度、峰顶下降控件与无信息量的径向轮廓图；新设计固定
`radial_lead_width_mm=0`、`radial_crest_drop_mm=0`。保存JSON仍记录这两项零值，
兼容已有构建器。旧候选缺少两字段或两字段为零可载入；任一非零值（包括通过
`--design` 载入）明确拒绝并提示径向功能已移除，避免隐藏的径向状态。历史实验
算法、资产与记录保持原状。
保存按钮只在当前参数已经成功显示后可用；保存提交已显示参数和点击时的姿态快照。
保存期间可以继续编辑，旧预览、导入响应和错误不会覆盖新编辑。显示连接中断时请刷新。
候选使用完整 UUID，在同目录写完临时文件后以不覆盖方式原子发布；历史8位UUID候选
仍可下载。此保证避免读取半个文件，不包含断电持久性承诺。

固定预览 OBJ 仅接受有限三维坐标、正索引三角面，支持已有的 `v/vt/vn` 与 `v//vn`
形式，忽略材质和输入法线并计算面法线。负索引、多边形、零面积面与其他几何记录
明确拒绝。正式生成器的冻结解析路径与几何算法保持原样。

预览二进制协议为 `petal-preview/v1`：4字节小端JSON长度、对齐到4字节的JSON、
每顶点6个float32（毫米坐标和法线）。客户端检查版本、长度、顶点数和有限数值，
格式错误时保留上次有效画面并禁用保存。请求体读取超时10秒；最多同时计算2个预览，
繁忙时返回503，客户端仅对当前参数最多重试2次；仍繁忙时可稍后再次调整参数重试。

默认忽略 `X-Forwarded-*`。本地反代需要显式配置浏览器可见的本地HTTP Origin，例如：

```bash
uv run python experiments/petal_designer.py --proxy-origin http://localhost:56343
```

可重复指定该选项；只接受本地HTTP Origin，不带路径。Host仍必须是回环地址。
SSH端口转发无需此选项，因为它保留浏览器的Host与Origin。

`clean_mesh` 的冻结契约是：米制坐标舍入13位，叉积模长须大于 `1e-18 m²`，
同一无向顶点集合重复时整组删除（包括同向或三重重复）；保留单独面的绕序。
它服务于生成器的零高度顶底面消除，不能替换为一般“重复面保留一个”。
