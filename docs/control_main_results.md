# 接触阶段刚度实验结果与证据边界

2026-10-04，整理已有 绕轴/横向释放实验 记录。
在固定模型、零重力、固定母头、单一起点与声明误差下，接触后绕轴刚度释放改变了
组合误差工况的落座结果；进一步改变 XY 刚度后，九点离散矩阵中的落座候选由 3 点
增加到 7 点，两个组合点仍失败。
这些结果用于说明特定方向的恢复刚度与当前卡滞现象之间存在值得关注的关系，
不用于声明该策略最优，也不自动决定 HexFrame 的系统控制方案。

## 绕轴释放实验：组合误差工况结果

同一误差为 XY=(2,−2) mm、偏航 +5°，物理步长和控制周期均为 0.5 ms。
三策略的其他轴、惯量、阻尼、轨迹与模型一致。横偏、相位与轴向间隙取保持末 1 s 最大值；
“落座候选”沿用历史综合门禁，包含几何、持续止挡、静止、载荷与内部安全检查。

| 绕轴策略 | 历史综合状态 | 横偏 mm | 相位误差 ° | 轴向间隙 mm | 持续止挡占比 |
|---|---|---:|---:|---:|---:|
| 固定高刚度 25 N·m/rad | FAIL | 0.0197 | 4.0129 | 4.49079 | 0% |
| 固定低刚度 0.5 N·m/rad | FAIL | 0.0088 | 0.4600 | 0.30619 | 0% |
| 0.5 → 0 N·m/rad，接触后释放 | CANDIDATE_PASS | 0.1658 | 0.0367 | 0.00108 | 100% |

固定低刚度组的横偏和相位虽小，仍未持续承载止挡；只看位姿接近不能代替落座判据。
释放组的横偏也不是三者最小，因此不能概括为“所有误差指标均改善”。
无误差和 XY=(2,−2) mm 两个补充释放点也达到落座候选，但本页不把它们作为三策略完整配对。
现有证据支持上述组合点的比较，不支持所有误差下的普遍优势。

## 横向释放实验：绕轴释放后进一步释放 XY

两策略保持相同绕轴释放，唯一控制变量是接触后 XY 刚度是否由 80 降到 0 N/m。
主对照均为 0.5 ms 物理步长、0.5 ms 控制周期和 10 mm/s 插入参考速度。
“原→新”表示仅绕轴释放→绕轴＋XY 释放。表内均为保持末 1 s 指标。

| XY mm / 偏航 ° | 落座候选：原→新 | 横偏 mm：原→新 | 轴向间隙 mm：原→新 | 止挡占比：原→新 |
|---|---|---:|---:|---:|
| (−6,0) / 0 | 否→是 | 0.2178→0.1412 | 0.06980→0.00000 | 0%→100% |
| (+6,0) / 0 | 否→是 | 0.2463→0.1400 | 0.11278→0.00000 | 0%→100% |
| (0,−6) / 0 | 否→是 | 0.2170→0.1424 | 0.06889→0.00000 | 0%→100% |
| (0,+6) / 0 | 否→是 | 0.2465→0.1438 | 0.11317→0.00000 | 0%→100% |
| (0,−6) / +15 | 否→否 | 6.3270→6.2789 | 16.31153→16.30935 | 0%→0% |
| (0,+6) / −15 | 否→否 | 6.3013→6.2503 | 16.30520→16.30307 | 0%→0% |
| (0,0) / 0 | 是→是 | 0.0059→0.0059 | 0.00000→0.00000 | 100%→100% |
| (2,−2) / +5 | 是→是 | 0.1658→0.0018 | 0.00108→0.00000 | 100%→100% |
| (0,0) / −15 | 是→是 | 0.0017→0.0017 | 0.00000→0.00000 | 100%→100% |

四个单轴 ±6 mm 点由失败变为落座候选，已有三个成功点保持成功。
两个组合点仍停在名义落座高度上方约 16.3 mm，相位误差仍约 15°。
这说明消除 XY 回拉不足以解决这些组合卡滞；不通过事后调阈值或新增搜索把它们改为成功。
单轴点与两个组合点界定的是已测试离散条件，不能推导连续捕获区域。
表中显示为零的间隙是舍入后的仿真量，不是实物制造精度。

小组合点的横偏明显减小，但相位误差由 0.0367° 增至 0.2090°，两者均在原门槛内。
因此两组对照的差异依据是更多测试点完成落座及具体误差表现，不是逐项支配仅绕轴释放。

## 时间与载荷可以支持什么结论

`first_loaded_stop_s` 是首次承载止挡时刻，不要求此后一直满足所有落座门禁；
`gate.duration_s` 是包含固定保持段的仿真时长，也不是通过判据的最早时刻。
两者都不能直接用作任务完成时间或证明效率提升。

| 横向释放实验 两策略均成功的点 | 首次承载止挡 s：原→新 |
|---|---:|
| nominal | 14.8285→14.8285 |
| 小组合 (2,−2) mm / +5° | 15.0945→15.1240 |
| 零 XY / −15° | 15.0845→15.0850 |

这些事件时间未显示一致提前。nominal 首次承载止挡还早于约 14.993 s 的释放触发，
不能用 nominal 的首次接触事件证明释放促成初次落座。
本阶段保留“效率优势未建立”，不为补一个排名重跑矩阵。
下一次系统运行应明确记录满足持续就位条件的时刻，再评价完成时间。

所选 23 条对照记录的接触载荷门禁均为 `PASS`；失败仍按原综合状态保留。
载荷用于解释量级、冲击与异常，不提出精确峰值降低比例。
历史粗步长 `SENSITIVE` 标签和已有较细步长记录继续作为补充限制；
不因这些标签继续增加接触精度实验。

## 与完整系统的关系

绕轴/横向释放实验 是接触阶段的局部机制实验，其结果不自动决定 HexFrame 的控制方案。
若未来将 SE(3) 阻抗、HQP-AC 或其他接触控制方法接入完整装配，需要满足的通用
系统约束（对接控制点、携带负载、反馈链路、力矩执行、时间设置与验收）见
[系统验证](system_validation.md)。

绕轴/横向释放实验 的当前阶段工作到此结束。已有结果作为接触阶段局部机制证据保留，
不继续追加刚度扫描或参数优化；不追加误差全网格、接触峰值收敛、搜索恢复或
新接口优化作为前置条件。
