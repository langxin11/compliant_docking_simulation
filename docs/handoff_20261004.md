100 Hz 保存状态最后 46.990 s、接触记录最后 46.999 s；原报告 `duration_s=53` 只是计划时长。
失败组仍由机械臂抓持，没有补演锁定。表中是实际两接口根之间的残差，不是轨迹跟踪误差。

模块 CAD 质量惯量保留，所以这只是几何移植原型，不代表新硬件负载已验证。

冠形保留原 STL、SDF、公头内部 40°；采样配合参考根间距 47.1874 mm、外部相位 4.25°。
通过固定挂载偏置与相位适配维持原模块布局，但参考并未证明当前 SDF 下无重叠：
存储初始约 0.559 mm 重叠、约 902 N 预载，存储全过程约 1410 N 与 1.993 mm 最大穿透。
