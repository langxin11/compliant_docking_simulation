# PetalDock100 替代接口：iiwa14 完整流程验证

> 本页为首轮固定刚度实验记录。当前入口已加入接触后的绕轴释放和固定控制周期，见 [后续验证](petal_contact_control_validation.md)；下方原始命令对应此轮保存的源码快照。

已完成 8 组完整机械臂对照：4 组达到本轮落座候选条件，4 组未通过。模型可作为可选接口使用，但含偏航误差的完整替换验收尚未通过；瞬时接触载荷对物理/控制时间步仍敏感。

## 接入与验证范围

- 可选场景：`scenes/iiwa14_petal_insertion.yaml`。复用现有 SE(3) 阻抗、路点规划和 iiwa14 仿真循环。
- 安装 frame 改为工具法兰根 `tool_dock`，相对原机械臂 attachment_site 无额外平移；配合旋转为 `Rz(45°) Rx(180°)`，名义法兰间距 46.4 mm。
- Pinocchio / MuJoCo 使用同一份展开的组装 MJCF，含新工具质量、质心和完整惯量张量；为新场景补齐机械臂关节范围。
- 附件自带凸碰撞分块已直接接入；只适配名称、资源路径和 F/T 锚点。没有执行附件导入脚本，模型内容使用重新生成的哈希清单。
- 零重力，侧方起点 → 估计目标上方 → 下降 → 对接 → 保持 8 s；真实目标只进入物理接触和评分。
- 初次直接沿用旧接口增益未落座，记录保留在 `runs/petal_iiwa14_validation/`。随后统一采用轴向刚度 1500 N/m、绕轴期望惯量 0.05 kg·m²、绕轴阻尼 1 N·m·s/rad；各对照仅改变绕轴刚度 25 / 0.5 N·m/rad。未放宽落座、载荷或数值比较阈值。

## 结果

| 定位误差 | 高绕轴刚度 25 | 低绕轴刚度 0.5 | 说明 |
|---|---|---|---|
| 无误差 | 落座候选通过 | 落座候选通过 | 最后一秒持续承载止挡接触 |
| XY = (2, −2) mm | 落座候选通过 | 落座候选通过 | 横向残差最大约 0.154 mm，最后一秒持续承载止挡接触 |
| XY + 5° 偏航 | 未通过 | 未通过 | 高刚度相位残差约 4.01°、离落座约 4.49 mm；低刚度约 0.46°、0.306 mm；两组均没有承载止挡接触 |
| XY + 5° 偏航，半步长 | 未通过 | 未通过 | 位姿和最终结论基本相同，瞬时载荷峰值未通过数值比较 |

低刚度组合组通过了位置进给、静止和载荷门禁，但没有真正承载止挡；外观贴近、深度达标不足以单独判定落座。新增几何门禁同时检查：横向 ≤0.5 mm、倾斜 ≤0.5°、相位 ≤2°、名义轴向间距偏差 ≤0.75 mm，最后一秒承载止挡接触占比 ≥95%。净接触载荷限制保持 40 N / 2 N·m。

## 半步长检查

物理和控制步长同时由 0.5 ms 改为 0.25 ms。几何差异很小，但两种刚度的接触力峰值都对时间步敏感：

| 绕轴刚度 | 接触力峰值 0.5 → 0.25 ms | 绕轴接触力矩峰值 0.5 → 0.25 ms |
|---|---:|---:|
| stiff | 7.043 → 7.980 N | 0.4331 → 0.4331 N·m |
| compliant | 4.292 → 6.497 N | 0.1709 → 0.2414 N·m |

两种刚度均未达到本轮预先声明的载荷峰值比较阈值。载荷仍低于场景安全门禁，但不能据此声称时间步已收敛。

## 失败机制与下一步

组合误差工况仍持续跟踪错误的估计偏航。低刚度组的目标 50°、实际约 45.459°，姿态恢复力矩约 0.03963 N·m，最终接触轴矩约 −0.03965 N·m。高刚度组对应约 0.43302 / −0.43307 N·m。这个平衡关系支持如下判断：持续的偏航恢复力矩与导向接触形成平衡，使接口悬停在止挡上方；降低刚度有明显帮助，当前固定 0.5 仍不足以落座。

下一轮优先做接触阶段的参数调度：接触后降低或释放绕轴恢复刚度，保留阻尼与倾斜约束；推进与止挡承载检查保持独立。再统一传感器反馈的时间与参考点，继续细化时间步，直到载荷峰值差异稳定后再扩展误差范围。改动应在同一个完整流程中成对验证，保持验收门槛。

## 验证与复现

11 个关节配置下，两套模型最大位置差 6.22e-15 m，旋转矩阵元素差 1.91e-14，质量矩阵元素差 2.93e-14。初始无接触，路径经过连续 IK 检查。8 组均无 MuJoCo 仿真警告，载荷平衡残差在浮点精度内。

208 项非慢速测试通过，4 项既有慢速测试未执行；7 条警告来自绘图依赖的弃用提示。新增测试涵盖完整工具惯量、共享模型一致性、关节范围、配合相位、真实/估计目标隔离、载荷紧凑记录与承载止挡验收。
