# PetalDock100：接触后的横向柔顺与物理步长验证

本轮（2026-10-03，北京时间）在同一完整接近、下降、插入和保持流程中，
比较仅绕轴释放与绕轴＋XY 释放。九个离散点的配对实验中，原策略 3/9 达到落座候选，
新策略 7/9；单轴 ±6 mm 的四个失败点转为落座候选，原先成功的三个点保留。
两个较大 XY＋偏航组合仍卡滞。没有验证连续捕获范围或锁紧。

## 实现与控制边界

`contact_yaw.lateral_stiffness_after: 0.0` 为可选配置。省略该字段保留原行为。
使用原轴向 F/T 载荷触发、滤波与保持检测，触发后共用 0.25 s 的平滑释放过程：
XY 刚度从 `[80, 80]` N/m 降到零，绕轴刚度从 0.5 N·m/rad 降到零。
阈值仍为 0.15 N，滤波 0.01 s、保持 0.02 s；触发只允许在插入/保持阶段并锁存。
轴向刚度 1500 N/m、倾斜刚度 25 N·m/rad、所有惯量与阻尼以及 0.15 mm 预紧不变。
这是被动接触引导下的横向释放，没有加入搜索动作、目标真值反馈或止挡状态反馈。

落座候选同时要求：保持末 1 s 横偏 ≤0.5 mm、倾斜 ≤0.5°、相位误差（模 90°）≤2°、
名义轴向间隙 ≤0.75 mm、至少 95% 样本持续承载止挡；线/角速度分别 ≤3 mm/s、2°/s。
全程接口净合力 ≤40 N、绕轴净接触力矩 ≤2 N·m，原进给/传感器/内部安全门禁也必须通过。

两策略同点的参考位置、触发时刻和触发前关节轨迹完全相同，最大关节差为零，
见 [配对检查](../runs/petal_lateral_control_20261003/matched_pair_checks.json)。
本轮全部配对均重新仿真，未复用旧记录；九组原策略的新关节轨迹也与旧网格逐步一致，
源码与附件模型哈希经过核验。控制周期和样本反馈延迟固定为 0.5 ms，物理加密不改变它们。

## 物理步长与峰值位置

预先选定 (−6, 0) mm、(0, −6) mm＋15°、零 XY＋−15° 三点，先比较 0.5/0.25 ms。
仅对敏感点追加 0.125 ms，上限三点。保持落座判定一致之外，还要求横偏和轴向间隙变化 ≤0.1 mm、
相位变化 ≤0.1°、合力峰值变化 ≤max(0.5 N, 原峰值 10%)、轴矩峰值变化 ≤max(0.05 N·m, 原峰值 10%)。

## 数据与软件核验

- 23 次完整仿真；九组主配对、三组半步长、2 组四分之一步长、0 组独立减速。
- 248 项非慢速测试通过，4 项慢速测试未执行；40 项针对性检查通过。7 条警告来自 SciencePlots 绘图依赖弃用。
- 所有数值通道有限；逐步重算保持末秒的几何与全程载荷门禁，与记录一致。
- F/T 按样本世界原点搬移到当前 body 坐标，时间年龄、位姿和载荷平衡独立核验。
- XY 刚度在触发之前保持 80 N/m，触发之后单调下降到声明值；没有提前释放。
- 仿真警告、非接口碰撞、限幅与关节越限异常记录：0 组。

## 使用与下一步

统一入口复现本轮矩阵（建议另选输出目录，源码/计划变化时拒绝在旧目录混跑）：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MUJOCO_GL=egl uv run python experiments/petal_insertion_suite.py \
  --lateral-study --jobs 3 --out runs/petal_lateral_reproduction --resume
```

单轴 −6 mm 演示场景为 `scenes/iiwa14_petal_lateral_insertion.yaml`，使用 0.25 ms 物理步长、
0.5 ms 控制周期及原参考速度；除名称/文件路径外与本轮对应半步长组有效配置相同。

```bash
MUJOCO_GL=egl uv run docking --scene scenes/iiwa14_petal_lateral_insertion.yaml --dt 0.00025
```

下一步优先处理已保留的组合卡滞：先用可观测位姿进展和 F/T 检测停滞，再单独评估有限范围搜索、
受限预紧与退出恢复。目标真值和止挡接触标签仍仅用于评分。尚未实施搜索或自动退回。
扩大误差、新起点、重力/惯性补偿和其他机械臂需分别完整复核。mjviser 仍是可选被动回放后端。

所有通过结果均只适用于零重力、固定母头、单一起点、声明几何和离散误差；没有焊接或模拟锁定，
`CANDIDATE_PASS` 表示本研究落座候选，不能解释为锁紧或实机认证。
