# 机械臂竖直花冠组装：完整流程

完整 49 秒流程已通过：存储锁定 → 机械臂捕获 → 解除存储锁 → 转运 → 原花冠凸分解接触 → 持续就位锁定 → 卸力确认 → 解除机械臂锁 → 撤离。接触是 MuJoCo 实际碰撞产生的载荷；模块在初始化后只通过动力学积分运动。

模块质量仍为场景原有 2 kg，主惯量为 `[0.00977708, 0.00977708, 0.01102083] kg·m²`，机械臂完整关节动力学参与求解。这些是仿真模型参数，不是实物测量。采用两个原花冠的各 130 个凸部件，摩擦 0.2，接触时间常数 8 ms。

原先 50 mm 的视觉安装间距改为采样几何参考 47.1874 mm；固定接口的安装相位调整至 175.75°，让两侧面接口的相对根坐标与独立花冠试验的 `Rz(4.25°)Rx(180°)` 一致。接口仍处在六个侧面，模块 1 的接口 4 向下对接模块 2 的接口 1。上方机械臂抓取接口保留原理想锁定模型，没有增加抓取处微接触。

接触阶段轴向参考速度限幅 1 mm/s，接触载荷用 20 ms 低通滤波；0.5 kg、200 N·s/m 轴向导纳，目标力 0.3 N 并渐增 1 s。100 Hz 更新参考逆运动学，1 kHz 力反馈与动力学。绕轴参考跟随实际角度的 80%，降低恢复约束并保留伺服阻尼；横向和倾斜用慢速补偿。它不是独立接口实验的完全零绕轴刚度，也不是论文算法复现。

锁定条件：力目标渐增完成、轴向力 0.15–0.6 N、安装位置误差 ≤0.75 mm、姿态误差 ≤0.5°、相对线速度 ≤0.5 mm/s、角速度 ≤0.5°/s、接触穿透 ≤0.3 mm、净接触力矩 ≤0.5 N·m，连续成立 0.5 s。确认后用实际位姿设定理想锁定，不瞬移模块。保持关节参考在锁定时的实测位置，去除速度前馈；抓取 weld 的前三个平移约束行合力 ≤0.2 N、关节速度模长 ≤0.002 rad/s 连续 0.5 s，才允许释放机械臂。

## 本轮结果

| 指标 | 数值 |
|---|---:|
| 首次接触 | 35.089 s |
| 连续就位后锁定 | 36.588 s |
| 机械臂释放 | 43.600 s |
| 峰值轴向接触力 | 1.075 N |
| 最大求解穿透 | 0.00240 mm |
| 释放时抓取约束合力 | 0.00638 N |
| 最终模块位置误差 | 0.0381 mm |

没有检测到已配置几何的结构碰撞、关节越限、力矩饱和或 MuJoCo 警告。载荷计入主动花冠接触对，抓取与模块间 weld 的反力不计入花冠载荷。净合力不能代替局部齿面载荷。

当前验证为单个名义完整流程；独立接口的偏差/半步长结果不能替代带机械臂的偏差与步长验证。锁紧仍是理想 weld，未模拟锁销、夹紧预紧或机构强度。完整流程也未加入自由漂浮基座、结构柔性和传感器噪声。
