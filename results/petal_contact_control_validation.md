# PetalDock100：接触后的绕轴释放与反馈同步验证

释放策略的四组完整流程均达到落座候选条件，包括无误差、XY 偏差、XY + 5° 偏航及组合误差的半步长复核；固定高/低绕轴刚度的组合工况仍未承载止挡。三种策略通过原先声明的两个物理步长比较。当前结论限于零重力、单一起点和声明误差，不代表锁紧或硬件认证。

## 实现与对照

- 复用 iiwa14 完整流程：侧方起点 → 估计目标上方 → 下降 → 插入 → 保持 8 s。模型、轨迹、关节范围、A/D 和其他 K 不变。
- 固定高/低绕轴刚度为 25 / 0.5 N·m/rad；释放策略从同一 0.5 开始。仅插入/保持阶段使用轴向 F/T 载荷：10 ms 滤波，超过 0.15 N 持续 20 ms 后锁存，0.25 s 平滑降到零。保留绕轴惯量、阻尼和倾斜约束；接触短暂消失不重新加刚度。
- 初版 0.3 N 高于无误差组约 0.225 N 的正常预紧力，导致已落座但未触发释放。这一试验及失败记录保留在 `runs/petal_contact_control_20261002/`；最终降低检测阈值后重新运行四组释放策略，落座与载荷验收门槛不变。
- 接触检测只用关节状态和 F/T 样本，不读取目标真值、仿真接触对或止挡标记。真值只用于物理评分与显示；规划仍使用有误差的估计目标。
- 控制周期固定为 0.5 ms。F/T 取上一控制周期首个物理求解的样本，延迟固定为 0.5 ms；初始反馈为零。保存采样时刻的 site 世界位姿，反馈前变换到当前控制 body 的原点与坐标轴。位姿、速度、F/T 和接触遥测统一到积分前求解时刻，没有额外约束求解。

验收门槛保持：横向 ≤0.5 mm、倾斜 ≤0.5°、相位 ≤2°、名义法兰间距 46.4 mm 的偏差 ≤0.75 mm，最后一秒承载止挡接触占比 ≥95%。同时检查静止、关节范围、非接口接触、力矩饱和、净接触力 ≤40 N、轴矩 ≤2 N·m。没有 weld 锁定。

## 时间步与反馈核对

仅将物理步长由 0.5 改为 0.25 ms，控制周期及反馈延迟保持不变。综合状态、几何差异及载荷峰值差均满足原比较标准：横向/轴向差 ≤0.1 mm、相位差 ≤0.1°；峰值力差 ≤max(0.5 N, 10%)，峰值轴矩差 ≤max(0.05 N·m, 10%)。

| 策略 | 接触力峰值 0.5 → 0.25 ms | 轴矩峰值 0.5 → 0.25 ms | 比较结论 |
|---|---:|---:|---|
| stiff | 7.043 → 7.043 N | 0.4331 → 0.4331 N·m | STABLE_IN_TWO_STEPS |
| compliant | 4.292 → 4.463 N | 0.1709 → 0.2041 N·m | STABLE_IN_TWO_STEPS |
| released | 4.292 → 4.248 N | 0.1534 → 0.1616 N·m | STABLE_IN_TWO_STEPS |

首轮同时缩小物理与控制步长，低刚度峰值力由 4.292 增至 6.497 N；本轮固定控制采样后为 4.292 → 4.463 N。这支持原比较混入控制频率/反馈延迟影响的判断。两个步长通过研究比较，不等于数学收敛证明；改变控制频率、接触参数或误差范围后需重新核验。

所有八组均无 MuJoCo 仿真警告、非接口接触、关节超限或力矩饱和。每组 `feedback_audit` 均通过延迟、坐标变换与求解位姿核对。`validation_audit.json` 还从原始 NPZ 重算几何评分、核对全部数值通道、来源哈希和释放前状态一致性。224 项非慢速测试通过，4 项既有慢速测试未执行，7 条警告为绘图依赖弃用提示。

## 数据来源与复现

最终矩阵包含四组重新计算的释放策略和四组有效配置逐项一致的固定刚度对照。固定工况的回路、物理/模型、控制器、反馈、规划、日志源码及资产哈希相同，原始 NPZ 未改变；变化只涉及它们未启用的检测阈值和输出路径。JSON 的 `provenance` 与 `provenance/reuse_fixed.py` 保存校验逻辑和原始文件哈希。初版 0.3 N 试验另存，不混入最终释放策略。

当前入口默认输出 `runs/petal_contact_control_20261002_v2/`。使用新目录复现完整八组：

```bash
OPENBLAS_NUM_THREADS=1 MUJOCO_GL=egl uv run python experiments/petal_insertion_suite.py \
  --case combined --profile stiff compliant released --setting baseline dt_half \
  --out runs/petal_contact_control_reproduction --jobs 2 --preview --resume
OPENBLAS_NUM_THREADS=1 MUJOCO_GL=egl uv run python experiments/petal_insertion_suite.py \
  --case nominal xy --profile released \
  --out runs/petal_contact_control_reproduction --jobs 2 --resume
```

输出保留有效场景、路点、逐步 NPZ、独立动态/接触/几何验收、反馈审计、源码快照、环境和文件哈希。脚本结束仅表示计算完成，结论以 `assessment` 为准。首轮见 [固定刚度接入记录](petal_iiwa14_validation.md)。
