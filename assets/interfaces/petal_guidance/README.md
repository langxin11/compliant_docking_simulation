# PetalDock100 导向几何原型

两个可选候选由 `experiments/prepare_petal_guidance.py` 生成，不覆盖原模型
`assets/interfaces/petal_dock100`。它们用于仿真对照，尚未生成制造用 STEP。

| 候选 | 角向轮廓 | 径向轮廓 | 导向凸碰撞块/侧 |
|---|---|---|---:|
| `narrow` | 平顶半角 4.21875°、端部圆滑的线性工作斜坡 | 保留原 1 mm 边缘圆滑 | 464 |
| `radial` | 与 `narrow` 相同 | 增加宽 6 mm、峰顶下降 3 mm、谷底抬升 3 mm 的互补导面 | 2512 |

原轮廓平顶半角为 8.4375°、工作面为五次曲线。`narrow` 同时改变平顶宽度和
斜坡曲线，因此本轮不能将结果归因于单独收窄平顶。

外径 100 mm、导向高度 18 mm、安装头、安装孔和止挡基准不变。两端仍使用同样的
四花瓣几何，配合姿态 `Rz(45°) Rx(180°)`，名义法兰间距 46.4 mm。径向导面满足
`h(r, θ) + h(r, 45° − θ) = 18 mm`；原边缘圆滑只会进一步留出间隙。

每个候选包含机械臂侧 `active.xml`、目标侧 `passive.xml`、可视 OBJ、凸碰撞网格、
更新后的完整装配质心与惯量、`model_info.json` 和内容哈希清单 `manifest.json`。
安装头、止挡的网格及质量贡献来自原适配模型。新惯量采用原完整装配加导面网格的
质量/一阶矩/原点惯量差，完整张量经平行轴变换移至新质心。

切换模型时同时替换两侧的 MJCF，以保持互补轮廓配合。

`radial` 按径向带分块以避免凸包填平谷底，计算开销明显高于 `narrow`。
网格质量积分的加密检查不能替代完整接触动力学的时间步、碰撞离散和材料验证。

统一对照入口：

```bash
MUJOCO_GL=egl uv run python experiments/petal_insertion_suite.py \
  --geometry-study --jobs 3 --out runs/petal_guidance_reproduction --resume
```

该入口沿用既有控制循环、摩擦和验收门槛，包含 27 次主对照及固定预算的 4 次
物理步长加密。仿真门禁只给出落座候选；没有锁紧机构或锁紧认证。

生成器仅在候选目录不存在时写入，拒绝覆盖已有版本。后续改变参数应使用新版本目录
和新输出目录，同时更新资产清单，避免不同几何混入同一对照。

本轮主对照中，`narrow` 的九个工况全部达到落座候选，原轮廓为 7/9。
`radial` 为 6/9，三个含 15° 偏航的工况虽然落座，但瞬态合力超限（最大约 244 N），
因此当前使用角向候选。三个角向代表点的 0.25/0.125 ms 比较符合原差异门槛；
这不替代完整数值收敛、制造或实机验证。
[完整验证](../../../results/petal_guidance_geometry_validation.md)。
